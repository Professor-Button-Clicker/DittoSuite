## Known Limitations

1. **All runtime tests NOT RUN.** This test suite was authored on Windows 11. The entire DittoSuite codebase is macOS-only Swift targeting macOS 14.0+. Every test requiring compilation, file I/O with macOS POSIX extensions (st_birthtimespec, listxattr), CryptoKit, or system binaries (/usr/bin/ditto, /usr/bin/hdiutil) could not be executed. These MUST be run on macOS before any production use.

2. **Code review cannot replace runtime testing.** The 89 PASS-by-code-review results confirm the logic is structurally correct, but cannot detect runtime errors (concurrency bugs, memory issues, CryptoKit API misuse, filesystem behavior differences).

3. **Upstream characterization has zero findings.** All 15 MUST-TEST-EMPIRICALLY items require running ditto and hdiutil on macOS. No empirical findings are available.

4. **Wrapper-vs-manual equivalence not tested.** Cannot invoke /usr/bin/ditto on Windows.

5. **No test compilation verification.** The test files have not been compiled with swiftc/xcodebuild. Syntax errors or import issues may exist.
